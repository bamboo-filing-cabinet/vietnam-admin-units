# Province code scheme changed in 2004 (3-digit → 2-digit)

Written 2026-07-10. Found while showing that pre-2025 changes exist but aren't
yet in our data. A diff of province snapshots across 2004 showed **all 64 codes
as "new"** — because the codes don't overlap: the coding *scheme* changed.

## Evidence (canonical `fetch_units`)

| as-of | count | first codes | Hà Nội / Hà Tây |
| --- | --- | --- | --- |
| 01/06/2004 | 61 | `101` Hà Nội, `103` Hải Phòng, `104` Vĩnh Phúc, `105` Hà Tây | `101` / `105` |
| 01/01/2005 | 64 | `01` Hà Nội, `02` Hà Giang, `04` Cao Bằng | `01` / `28` |

Pre-2004 uses **3-digit** codes; from ~2004 the current **2-digit** scheme
(Decision **124/2004/QĐ-TTg**). The `.02` bisect put the count change 61→64 at
**2004-06-30**; the scheme switch coincides with it (exact date not re-bisected).

## Why it matters

1. **Two changes were conflated.** "2004 splits 61→64" (`.02`, `.12`) is really a
   **renumbering + splits** at once. Keyed by code, the whole country looks
   replaced across that boundary — a false signal.
2. **Cross-era code matching is worse than the 2025 case.** We already knew codes
   are *reused* across the 2025 reform (`.02` A1). Now we also know the **entire
   scheme changes** at 2004. So over the full 2002→2026 span there are ≥2 code
   discontinuities. Lineage across the 2004 boundary **cannot** use code equality
   — must use name + territory (the Đối Chiếu crosswalk / Lịch Sử), same as the
   2025 tier. Reinforces the repo-owned `local_id` spine (`(scheme?, code, era)`
   is not even enough — name/territory is the anchor).
3. **Historical `local_id`** needs care: `p-{code}-{era}` assumes a stable code
   format; pre-2004 3-digit codes must not collide with 2-digit ones. Prefix by
   scheme/era, or don't parse codes as integers.

## Answer to "why no pre-2025 data?"

Correct — the committed dataset covers **only the 2025 reform** (Phase-1 scope:
snapshots `2025-06-30` + `2026-07-10`, entities/lineage for that one boundary).
Pre-2025 changes are **real and measured** (this journal, `.12`, `.13`) but **not
yet ingested**. Capturing them (2002 floor, 2004 renumber+splits, 2008 Hà Tây,
2019–24 ward waves, chained lineage) is Phase 2 — and Phase 2 must handle the
2004 code-scheme change as a first-class discontinuity, not just the 2025 reuse.
