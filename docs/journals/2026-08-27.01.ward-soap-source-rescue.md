## Rescue workflow added

`python -m vn_admin_units.ward_rescue` now:

1. fetches exact `DanhMucPhuongXa` response bytes through the canonical SOAP
   request path;
2. validates that the response parses into a non-empty ward roster before it is
   accepted;
3. stores exact response content as deterministic
   `data/raw/soap/DanhMucPhuongXa_YYYY-MM-DD.xml.gz`;
4. records URL, method, ordered parameters, retrieval timestamp, stored-artifact
   and decoded-content sizes/SHA-256 values, roster identity/duplicate metrics,
   and acquisition reasons in `data/raw/manifest.jsonl`;
5. verifies the gzip artifact, lossless decode, and exact decoded response hash
   before treating an existing payload as complete;
6. skips verified dates on rerun, retries transient failures with exponential
   backoff, and stops after the first exhausted date by default so an unavailable
   source is not hammered; and
7. supports `--limit` for short recovery windows and repeatable `--date` for
   surgical acquisition.

The SOAP transport now exposes `fetch_units_raw`, returning response bytes
without a decode/re-encode round trip. Existing parsed callers retain their
original behavior through `soap_call`.

## Compressed-storage contract

The storage gate is **closed**. SOAP snapshots use a filename-free level-9 gzip
stream with `mtime=0`, making the wrapper deterministic. The manifest records:

- `sha256` / `bytes` for the committed `.xml.gz` artifact;
- `content_sha256` / `content_bytes` for the exact SOAP response;
- `storage_encoding: gzip`, `compression_level: 9`, and
  `compression_mtime: 0`; and
- retrieval provenance plus parsed roster metrics.

`rawcache.read_raw` transparently returns the verified decoded bytes. Existing
plain critical files were migrated only after their compressed replacements
passed both integrity checks; their original `retrieved_at` and response hashes
were preserved. No XML was reserialized.

Run the history scope in reviewed batches, committing only after the manifest
and coverage audit passes. Reruns verify and skip every completed gzip artifact.
