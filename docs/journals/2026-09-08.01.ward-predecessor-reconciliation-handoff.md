## Implementation completed in this checkpoint

district:

- the primary and broad passes consider all valid historical parent spans and
  comma-qualified names;
- an article pass uses Vietnamese Wikipedia page identity and article evidence;
- a context pass uses broader Wikidata search/entity context;
- a GeoNames pass uses the saved Vietnam dump and P1566 identities;
- the current-unit reconciler normalizes P1566 values;
- the CREATE emitter consumes and fingerprints all reconciliation passes; and
- the random-audit collector always fetches successor entities, preventing
  incomplete evidence when a successor was absent from search results.

`data/raw/manifest.jsonl`. New generated artifacts and tests for the article,
context, and GeoNames passes are included in this checkpoint.
