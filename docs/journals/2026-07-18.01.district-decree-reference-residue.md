## What was done

Two search passes over the changed-row decree codes captured from the 23 cached
district Đối Chiếu windows (`data/raw/crosswalk/district_20*.xls`). Each code was
disambiguated by its **effective date + province** (bare CP-era codes carry no
year in the crosswalk cell), and every hit was verified against the landing
document, not just a snippet.

- **Pass 1 — thuvienphapluat.vn.** WebSearch by reconstructed `<code>/<year>` +
  title + province. **+53** `van-ban` URLs, **+5** typo-variant keys (a garbled
  crosswalk cell pointing at the same doc as an already-resolved code, e.g.
  `135/206/NĐ-CP`→`135/2006`, `829/UBTVQH14`→`829/NQ-UBTVQH14`).
- **Pass 2 — hard tail, authoritative-gov fallback** (= the README's open-decision
  option **(a)**). Identity was already known; agents hunted the exact page and,
  when thuvienphapluat wouldn't surface, accepted a verified
  `chinhphu.vn` / `congbao.chinhphu.vn` / `luatvietnam.vn` / `dangcongsan.vn` URL.
  **+15** high-confidence gov URLs.

**`data/decree-urls.json`: 63 → 136.** Suite 91 passed; committed on `main`.

Mechanism note (still true, journal `2026-07-13.02`): the crosswalk decree column
is a *later* "last-touching" instrument, and the Nghị định *list* titles name the
**province**, not the district — so reference URLs cannot be scraped, they are
curated here per code.
