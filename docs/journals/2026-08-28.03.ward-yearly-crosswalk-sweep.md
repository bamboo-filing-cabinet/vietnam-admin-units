# Ward yearly crosswalk sweep complete

**Date:** 2026-08-28

**Source:** NSO `Doi_Chieu_Moi.aspx`, `Cấp = Xã`, official Excel export

**Plan:** `docs/plans/2026-08-28-phase3-ward-historical-source-closure.md`, Task 1

## Outcome

The ward historical yearly crosswalk inventory is complete and available
offline:

- 21/21 yearly windows verify (`2004→2005` through `2024→2025`);
- 18 previously missing yearly `.xls` exports were preserved;
- 24/24 total ward crosswalk artifacts verify when the long-range and two
  special 2025/post-2025 windows are included;
- all 24 files parse with the expected 13-column ward schema;
- parsed row counts equal manifest row counts for every file; and
- the complete ward crosswalk cache contains 256,149 parsed rows with zero hash
  or manifest-row mismatches.

This closes the availability-sensitive acquisition step. It does not by itself
prove complete event lineage: yearly crosswalks are net comparisons and still
require SOAP-delta, legal-index, and targeted-window reconciliation.

## Starting inventory and preflight

The cache began with six verified ward exports:

1. `ward_2002-01-01_2025-06-30.xls` — long-range net comparison;
2. `ward_2017-01-01_2018-01-01.xls` — yearly sample;
3. `ward_2019-01-01_2020-01-01.xls` — yearly sample;
4. `ward_2024-01-01_2025-01-01.xls` — yearly sample;
5. `ward_2025-06-30_2025-07-01.xls` — reform boundary; and
6. `ward_2025-07-01_2026-08-27.xls` — post-reform comparison.

The new offline preflight derived 21 expected yearly paths, found the three
yearly samples above, reported exactly 18 missing windows, and found no invalid
cached ward artifact. That matched the locked plan before the browser opened.

## Fetcher safeguards added

`vn_admin_units.crosswalk_fetch` now:

- prints a cache-only `--preflight` checklist;
- skips verified raw artifacts by default;
- supports explicit `--force` rather than silently replacing source files;
- launches no browser when every requested artifact already verifies; and
- retries transient failures by starting a fresh browser session and resuming
  from the remaining unverified windows.

Two source download attempts were canceled during the sweep. The first
completed file remained verified, and the retry path later demonstrated that a
fresh session skipped every completed year before continuing. No manual raw-file
repair or derived-data substitution was used.
