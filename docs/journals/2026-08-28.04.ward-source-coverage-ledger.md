## Legal-index denominator correction

The ward classifier selects **453 rows across the legal index's full date
range**. The SOAP rescue's 2005 date floor uses **392** of those rows, occupying
the previously reported **179 distinct effective dates**. The remaining 61 rows
are effective before 2005 and remain in the ledger because the historical scope
starts with the 2002 SOAP floor.

This corrects the earlier shorthand “453 instruments / 179 dates from 2005”:
453 is the all-date candidate-row count, while 179 is the distinct-date count
after the 2005 planning floor.

## Duplicate legal-index keys

Four `(code, effective date)` keys occur twice, so 453 candidate rows represent
449 unique instruments:

- `15/2004/NĐ-CP@2004-01-24` — exact duplicate title;
- `47/NQ-CP@2013-04-04` — comma/semicolon title variant;
- `1107/NQ-UBTVQH14@2021-02-01` — `Vĩnh Thanh Trung` / `Vĩnh Thạnh Trung` source
  spelling variant; and
- `1240/NQ-UBTVQH15@2024-12-01` — spacing variant around `2023-2025`.

The ledger uses one stable instrument ID per key, records `index_occurrences`,
and preserves every distinct title variant. It does not invent suffix IDs or
silently discard the duplicate rows.

Everything else remains explicit:

- 415 instruments have classification `unresolved`;
- 415 instruments have source status `missing`;

This is the intended Task 2 state. Task 3 discovers normalized SOAP changes;

## Implementation and gates

`vn_admin_units.ward_source_coverage`:

1. verifies each SOAP, crosswalk, and cached legal artifact through `rawcache`;
2. rejects duplicate raw-manifest paths;
3. locks the recovered source counts and source-floor/as-of dates;
4. groups legal-index variants by normalized code + ISO effective date;
5. distinguishes official primary artifacts from secondary URLs;
6. reuses the already audited 2025 source pairs without re-scraping; and
7. serializes stable, sorted, timestamp-free JSON.

Commands:

```sh
uv run python -m vn_admin_units.ward_source_coverage
uv run python -m vn_admin_units.ward_source_coverage --check
uv run pytest tests/test_ward_source_coverage.py -q
uv run pytest -q
```
