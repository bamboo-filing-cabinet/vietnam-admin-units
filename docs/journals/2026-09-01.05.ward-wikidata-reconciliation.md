## Performance shape

Discovery is one set-based query against
`https://qlever.dev/api/wikidata`. It uses explicit prefixes, has no
`SERVICE wikibase:label`, and aggregates labels, aliases, types, and parents
before returning one row per item. The saved response contains 11,838 unique
items. QLever reported 739 ms of query time.

The network and offline stages are deliberately separated:

1. QLever discovers the whole ward-class candidate universe once.
2. Local name and parent indexes select candidates for the 3,321 current
   wards.
3. Bulk `P131` evidence removes candidates whose parent cannot resolve through
   a current or former province/district QID to the ward's current province.
4. The remaining 2,878 QIDs are verified through 58 `wbgetentities` batches of
   at most 50 items.
5. Ordinary rebuilds load the compact cache and do no network I/O.

The Action API reader retries both HTTP failures and JSON-level API errors. A
batch is accepted only when every requested QID is present in the response.
This matters because the API can return a JSON error document with HTTP 200;
silently treating that response as a set of missing items produced an invalid
intermediate run and is now covered by a regression test.

## Matching and audit result

Automatic assignment requires all of the following current evidence:

- a folded Vietnamese/English label match, with aliases used only when no
  label candidate exists;
- a ward-tier `P31` among xã, phường, thị trấn, or đặc khu;
- a `P131` that resolves to the entity's current province, including through
  the complete province and former-district mappings; and
- no `P576` at or before the graph's `2026-08-27` as-of date.

All 11,223 non-current graph entities remain

The audit reports zero structural issues, zero assigned-QID collisions, and
10 non-fatal collisions in the deliberately broad folded-name key. Automatic
duplicate assignment is fail-closed: if one QID independently matches more
than one current row, all affected rows remain unassigned. This caught
Q10783690, whose labels and aliases span both current Sông Trí and Kỳ Anh.

## Reproduction

The normal check is completely offline:

```sh
uv run python -m vn_admin_units.ward_reconcile --check --audit
```

Refresh the dated live inputs only when intentionally taking a new Wikidata
snapshot:

```sh
uv run python -m vn_admin_units.ward_reconcile \
  --fetch --verify-current --audit
```

`--strict` remains expected to fail until every current row is either mapped or
explicitly acknowledged as a Wikidata gap. At this checkpoint, the next task
was review of the 926 unassigned current rows. Statement generation and any
Wikidata write remain separately gated after that review.
