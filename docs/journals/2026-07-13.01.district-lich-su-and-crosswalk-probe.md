# District-level Lịch Sử and crosswalk probe

Written 2026-07-13. Scouting the GSO website for district-level data to inform
Phase 2 (districts).

## Source 1 — Lịch Sử page (Lich_Su_Moi.aspx) at district level

**URL:** `https://danhmuchanhchinh.nso.gov.vn/Lich_Su_Moi.aspx`

### Controls

- **Cấp** dropdown: Tỉnh / **Huyện** / Xã
- **Thời điểm** date picker (point-in-time snapshot date)
- **Mã** / **Tên** text filters
- **Checkboxes:** Toàn bộ (all), Tại thời điểm (at point in time), Khoảng thời
  gian (date range with Từ ngày / Đến ngày)
- **Thực Hiện** (Execute) button
- **Xuất Excel** button — present in the DOM (ref_130) but **not visually
  rendered** on the Huyện view. May be Tỉnh-only, or may require login. Did not
  produce a download when clicked programmatically. **Not a viable export path
  for districts.**

### Behavior at Huyện level

- Setting Cấp=Huyện with Thời điểm=13/07/2026 (post-reform): **no data** — the
  district tier was abolished on 2025-07-01, so no districts exist at that date.
- Setting Thời điểm=30/06/2025 with Toàn bộ checked: **696 districts** returned
  (matches SOAP `DanhMucQuanHuyen` count exactly).
- **Columns:** Mã (3-digit code), Tên, Tên Tiếng Anh, Cấp (Huyện/Quận/Thị
  xã/Thành phố), Nghị định (decree ref + date), Mã TP (province code), Tỉnh/
  Thành Phố.
- **Expand [+] buttons** on each row show the district's constituent wards/
  communes (child units), **not** a change-event history. So this view is a
  hierarchical inventory, not a timeline.
- **Nghị định column** shows the decree that created/last modified each district,
  with dates spanning 2002–2024. Examples:
  - `Số: 135/206/NĐ-CP; Ngày: 14/11/2006` (Huyện Mường Ảng)
  - `Số: 45/NQ-CP ngày 25/8/2012; Ngày: 25/08/2012` (Huyện Nậm Pồ)
  - `Số: 131/NQ-CP; Ngày: 27/12/2013` (Thành phố Lai Châu)
  - `Số: 864/NQ-UBTVQH14; Ngày: 10/01/2020` (Huyện Hà Quảng)
- **Red/highlighted rows** indicate districts with changes (e.g. code 004 Quận
  Long Biên, code 106 Huyện Tam Đường).
- **District types visible:** Quận (49), Huyện (508), Thị xã (52), Thành phố (87)
  — four `LoaiHinh` flavors as expected from SOAP.

### Conclusion on Lịch Sử for districts

The Lịch Sử page at Huyện level is useful as a **browsable inventory** with
decree references, but it does **not** provide a change-event timeline or
old→new lineage. The expand view shows children (wards), not history. The Excel
export button is not functional at this level.

**Not the primary data source for district lineage.** Use the crosswalk instead.

## Source 2 — Đối Chiếu (crosswalk) page at district level

**URL:** `https://danhmuchanhchinh.nso.gov.vn/Doi_Chieu_Moi.aspx`

### Controls

- **Cấp** dropdown: Tỉnh / **Huyện** / Xã
- **Ngày gốc** (base/old date)
- **Ngày đối chiếu** (compare/new date)
- **Tỉnh** dropdown (filter by province, or blank for all)
- **Có thay đổi** checkbox (show only rows with changes)
- **Thực Hiện** (Execute) and **Excel** buttons

### Behavior at Huyện level

Tested with Ngày gốc = 01/01/2002, Ngày đối chiếu = 30/06/2025, Có thay đổi
checked. **This works and is the goldmine for district lineage.**

### Columns

| Column | Meaning |
| --- | --- |
| **Tỉnh** | Province code (old side: 3-digit like `101`, `201`, `203`) |
| **Tên Tỉnh** | Province name |
| **QH** | District code at base date (**5-digit**, e.g. `10101`, `20111`) |
| **Tên QH** | District name at base date |
| **Nghị định** | Decree reference (on the right edge, truncated in browser view) |
| **Ngày hiệu lực** | Effective date |
| **Tên QH ĐC** | District name at compare date |
| **QH ĐC** | District code at compare date (**3-digit**, e.g. `001`, `031`) |

### Key findings

1. **2004 code-scheme change confirmed for districts.** Old (pre-2004) district
   codes are **5-digit** (province prefix + 2-digit district, e.g. `10101` = Ba
   Đình in province 101 Hà Nội). New (post-2004) codes are **3-digit** (e.g.
   `001`). The crosswalk maps old→new directly. This resolves the open question
   from journal `.15`.

2. **New districts (created after 2002)** appear as rows with no old-side entry.
   Examples: Quận Long Biên (004), Quận Hoàng Mai (008) — Hà Nội districts
   created from rural areas.

3. **Dissolved/merged districts** appear as rows with no new-side entry.
   Example: Huyện Thông Nông (20307, Cao Bằng) — dissolved, likely merged into
   another district.

4. **Type upgrades** visible: Thị xã Cao Bằng (20301) → Thành phố Cao Bằng
   (040) with decree reference.

5. **Province code renumbering** also visible: old province codes are 3-digit
   (`101` Hà Nội, `201` Hà Giang, `203` Cao Bằng) → post-2004 codes are 2-digit
   (`01`, `02`, `04`).

### Excel export

**The Excel button works on the Đối Chiếu page.** It triggers a file download
(requires clicking "Save" in Chrome's download dialog if Chrome is configured to
ask for download location).

Downloaded file: `Đối chiếu đơn vị hành chính cấp Huyện _ 01_01_2002 và
30_06_2025 .xls` (305 KB).

This is the **primary data source for Phase 2 district lineage**. The file name
encodes the level and date range.

## Operational notes

- **Chrome download setting:** The user's Chrome is configured to ask where to
  save downloads ("Ask where to save each file before downloading"). Automated
  clicks on the Excel button will appear to fail silently until the user manually
  confirms the save dialog. Account for this in any automated workflow.
- **Lịch Sử Xuất Excel:** Not visible/functional at Huyện level. Don't rely on
  it.
- **Đối Chiếu Excel:** Works. Use this for data export.
