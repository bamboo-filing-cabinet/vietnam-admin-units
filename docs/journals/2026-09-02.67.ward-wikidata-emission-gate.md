# Ward Wikidata emission gate and current-item package

**Date:** 2026-09-02

## Finding

The completed current-unit review did not imply that the 2025 lineage was ready
to emit. `mappings/wards-qid.csv` contains every graph entity, but all 11,223
historical rows are intentionally `deferred-historical` and have no QID.

For the 2025 slice specifically:

| Measure | Count |
| --- | ---: |
| Reform edges | 10,586 |
| Distinct predecessors | 10,035 |
| Reconciled predecessors | 0 |
| Distinct successors | 3,316 |
| Reconciled successors | 3,158 |
| Edges with both endpoint QIDs | 0 |
| Edges with official reference URLs | 10,586 |

The five current special zones without ward predecessors already have QIDs and
do not account for the 158 current gaps. Every current gap participates as a
2025 successor. Full lineage emission is therefore blocked by 10,035 historical
predecessor QIDs and 158 current successor QIDs.

## Implemented local gate

Added `vn_admin_units.ward_emit`, which:

- measures and serializes endpoint/reference readiness;
- fails closed if ward lineage rendering is requested before complete endpoint
  closure;
- rejects same-QID predecessor/successor edges and non-ending 2025 relations;
- renders referenced `P576`, `P7888`, `P1366`, and `P1365` only after the gate
  passes;
- performs no Wikidata write.

The readiness result is committed as
`data/ward-wikidata-emission-readiness.json` so the blocker is visible without
repeating an exploratory analysis.

## Current creation package

The 158 `reviewed-unresolved` current rows all have:

- a retained-unresolved human decision;
- a reconciled current province QID;
- a known ward class (`133 Xã`, `25 Phường`);
- one signed 2025 establishing-resolution URL.

The generator writes `data/ward-wikidata-create-current.json` and one
consolidated `statements/na-wards-create-current.qs` file. The manifest retains
sixteen logical review groups and preserves candidate QIDs checked, review note,
and rationale.
Each CREATE block has `Lvi`, `Dvi`, `Sviwiki`, `P31`, `P17`, `P131`, and
`P571`; every statement is referenced to the signed province resolution. The
viwiki sitelink is emitted only after the live preflight resolves exactly one
unlinked current-unit page.

These files are **prepared, not uploaded**. The first live duplicate/sitelink
preflight cleared all 158 items with zero linked current articles and zero
confirmed duplicates. Its saved evidence and freshness gate are documented in
[`2026-09-02.68`](2026-09-02.68.ward-wikidata-create-preflight.md). Refresh it
immediately before upload. Successful QIDs must be recorded before the file is
regenerated or reused.

## Decision

Do not weaken the lineage gate by skipping missing endpoints. The next
implementation slice is bulk reconciliation of the 10,035 immediate pre-2025
predecessors. The remaining 1,188 historical entities can follow for full
2002-present history after the reform slice closes.

Detailed sequencing is in
`docs/plans/2026-09-02-phase3-ward-wikidata-emission.md`.
