## Explicit historical exceptions

The `2004-01-01 → 2004-07-01` event is classified as one 21,287-component
`code_only` source-scheme transition, not 10,537 dissolutions plus 10,750
creations. The 18 legal instruments effective inside that interval remain
source-only evidence. The four old/new code pairs omitted by every retained
crosswalk are still listed as eight named `crosswalk_omission_component_ids`;
they are explicit source exceptions rather than inferred identity edges.

### Resolutions 14 and 15 of 2008

The NSO index contains two malformed `14/2008/NĐ-CP` rows dated 2008-07-02 and
2008-08-03. Both are classified as duplicate/superseded representations of the
canonical `14/2008/QH12@2008-07-01`. The correction is derived-only and lives
in `data/ward-legal-linkage-overrides.json`; no raw source was rewritten.

The `2008-07-02 → 2008-08-03` SOAP event is now linked to:

- Resolution 14 for the delayed observed transfer of Xã Tân Đức from Hà Tây to
  Việt Trì, Phú Thọ; and
- the already archived Resolution 15 for the remaining 338 same-code
  province/parent changes associated with the Hà Tây absorption and related
  transfers.

Two removals at that boundary are stale Văn Khê and Ngọc Sơn source rows. They
are classified as source cleanup rather than new legal lineage. Resolution 14
has an official government-domain URL but is not yet archived; it therefore
remains `official_url_unarchived` and correctly keeps the Task-7 source gate
open.

## Implementation and verification

`vn_admin_units.ward_legal_linkage` performs the deterministic review and
event linkage. `data/ward-legal-linkage-overrides.json` is deliberately small:
it contains only the two malformed index rows, the canonical 2008 resolutions,
and the 2004/2008 event exceptions. The coverage ledger fingerprints both that
curation file and the 2025 composition artifact.

Commands:

```sh
uv run python -m vn_admin_units.ward_source_coverage
uv run python -m vn_admin_units.ward_source_coverage --check
uv run pytest -q
```

The full suite passes with 190 tests.
