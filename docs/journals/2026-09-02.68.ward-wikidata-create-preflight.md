## Reproducible method

`vn_admin_units.ward_create_preflight` performs only read operations:

1. one bulk QLever query checks exact Vietnamese/English labels and aliases;
2. 158 bounded `wbsearchentities` requests catch search-index variants;
3. one batched `wbgetentities` pass verifies all candidate claims and sitelinks;
4. batched Vietnamese Wikipedia title requests resolve the current article and
   read its `wikibase_item` page property.

The concrete query is saved at
`queries/ward-wikidata-create-preflight.rq`. The complete per-item result,
including article revision IDs, candidate entity revision IDs, dispositions,
and reason codes, is saved at
`data/ward-wikidata-create-preflight.json`.

Run immediately before upload:

```sh
uv run python -m vn_admin_units.ward_create_preflight --fetch --audit
uv run python -m vn_admin_units.ward_create_preflight \
  --check --require-upload-ready --max-age-hours 24
uv run python -m vn_admin_units.ward_emit \
  --check --require-current-create-ready --max-preflight-age-hours 24
```

The first command refreshes the live evidence. The latter two fail if any
article acquires a QID, a candidate becomes unresolved, an input changes, a
revision-pinned manual decision becomes stale, or the report is over 24 hours
old.

## Decision

The consolidated CREATE package is clear for human upload only while the
freshness and revision gates above pass. After upload, immediately record every
new QID in `mappings/wards-qid.csv` and regenerate the package. Never replay a
successful CREATE file.

The emitter uses each verified subject page to add one `Sviwiki` command to the
same CREATE block. This follows the
[QuickStatements sitelink syntax](https://www.wikidata.org/wiki/Help:QuickStatements#Adding_labels,_aliases,_descriptions_and_sitelinks)
and avoids leaving the created items detached from the articles that establish
their notability and identity. If the preflight is missing or no longer matches
the source inputs, the emitter writes no CREATE statements. The explicit
24-hour freshness check blocks upload when the live evidence is too old.
