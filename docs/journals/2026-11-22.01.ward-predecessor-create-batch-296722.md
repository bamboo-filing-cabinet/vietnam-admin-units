## Known issues with created items

The 2,165 successfully created items were uploaded with the **pre-correction
English label and description format**:

- **Len (English label):** includes the Vietnamese tier prefix, e.g.
  `Phường Ngọc Hà` instead of the correct bare name `Ngọc Hà`
- **Den (English description):** includes the Vietnamese parent tier prefix,
  e.g. `former ward in Quận Ba Đình, Vietnam, dissolved 2025` instead of
  `former ward in Ba Đình district, Vietnam, dissolved 2025`

The code in `ward_emit_predecessor_create.py` was updated during this session
to produce correct English labels (bare place names) and descriptions (English
tier suffixes), but the batch was created before those fixes were applied.
