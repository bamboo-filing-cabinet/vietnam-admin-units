## Why 15 targeted windows

The annual pass requested an exact observation-to-observation export only for:

- four codes that changed more than once within one annual window;
- one code that appeared and disappeared within the same annual window;
- five intervals containing partial-transfer composition evidence;
- two early-2025 events with no primary annual window; and
- concentrated SOAP/crosswalk disagreements, including one event with multiple
  same-date candidate instruments.

All dates came from retained SOAP observations. This is 15 targeted exports,
not the 369-date emergency ceiling. The NSO site returned all 15 successfully;
each verbatim `.xls` was parsed, hashed, row-counted, and added to
`data/raw/manifest.jsonl`. Fourteen exact windows fully reconciled.

The files remain verbatim `.xls`, not gzipped, for the same reason as the annual
sweep: Git compresses object transport and the source files stay directly
inspectable. The derived 40.2 MB JSON also remains plain, under GitHub's
practical 50 MB warning threshold after removing duplicated SOAP observations
and retaining references to the fingerprinted Task-3 artifact instead.
